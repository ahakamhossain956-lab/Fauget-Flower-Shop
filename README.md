# 🌸 Fauget Blooms - E-Commerce Flower Shop Landing Page

A clean, responsive, and modern e-commerce landing page built for **Fauget Blooms**, a premium online flower shop. Designed with HTML5 and styled using Tailwind CSS for a seamless shopping experience.

👨‍💻 **Developer:** [Ahakam Hossain](https://github.com/ahakamhossain956-lab)  
🔗 **Live Demo:** [https://fauget-flower-shop.vercel.app/](https://fauget-flower-shop.vercel.app/)

---

## ✨ Features

* **Navigation Bar:** Fixed top banner, brand logo, navigation links (`Home`, `Shop`, `Occasions`, `About Us`, `Contact`), search icon, wishlist, and cart drawer button.
* **Hero Section:** Eye-catching design with a promotional badge, call-to-action buttons, key statistics (100% Fresh Guarantee, Same Day Delivery, 4.9★ Rating), and featured hero image.
* **Featured Products Grid:** Showcase of top products ("Blooms & Plants") with price tags, badges (`Best Seller`, `Sale`), and an "Add to Cart" button for each item.
* **About / Feature Highlights:** Section highlighting core brand values (Custom Handcrafted Work, Express Same-Day Delivery, Eco-Friendly Packaging).
* **Deals & Discounts Banner:** Visual grid showcasing featured offers (e.g., 30% Off Spring Tulips, 25% Off Luxury Roses, 20% Off Mini Succulents).
* **Newsletter Subscription:** "Join Our Floral Circle" callout section for user email opt-in.
* **Footer:** Comprehensive footer with store details, location, quick navigation links, customer support options, and social media links.
* **Fully Responsive:** Looks great across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic layout structure.
* **Tailwind CSS:** Modern utility-first CSS framework for responsive layout and styling.
* **Vercel:** Fast and reliable continuous deployment and hosting.
